# scinote-web 领域模型总结

> 生成日期：2026-09-06（子域展开于同次续作）
> 依据：codebase-memory 知识图谱（`app/models` 下 173 个模型类）+ 核心模型源码核对
> 用途：项目领域模型（业务实体及其关联）的结构化速查

## 一、全局边界与架构特征
- **多租户（按 Team 隔离）**：`Team` 是顶层工作空间根，绝大多数业务实体直接或间接 `belongs_to :team`（或经父级 `delegate :team`）。共享数据库、按 `team_id` 分片，无独立 schema。
- **规模**：`app/models` 下共 **173 个模型类**（含 concern、STI 子类、异常类），图谱统计 1858 个 Class 节点。
- **命名惯例**：`MyModule` 在 UI/业务层即「任务（task）」；`Repository` 即「库存（inventory）」；`Protocol` 是「实验协议/步骤模板」。
- **大量 Concern 复用**（横向切片）：`SearchableModel`、`ViewableModel`、`Assignable`、`PermissionCheckableModel`、`ArchivableModel`、`TimeTrackable`、`Favoritable`、`MetadataModel`、`Cloneable`、`ObservableModel`、`TinyMceImages`、`PrefixedIdModel`、`SettingsModel`、`VariablesModel`、`ActiveStorageConcerns`、`VersionedAttachments`、`PinningModel`、`GenerateNotificationModel`、`Shareable`。

## 二、核心聚合与关系（自顶向下）

```
Team ──< Project ──< Experiment ──< MyModule(task)
                                         │
            ┌──────────────┬─────────────┼──────────────┬─────────────┐
         Protocol      Result        Tag/Tagging   Connection    MyModuleRepositoryRow
            │              │            (多态)       (→MyModule)        │
         Step            ResultText                inputs/outputs   RepositoryRow
       ┌─┬─┬─┐          ResultAsset                    │              │
   StepText Asset Table  ResultTable              (有向依赖)      RepositoryCell/*Value
   Checklist FormResponse                                      ↑
                                                       Repository(库存)
```

### 1. Team（团队）— 聚合根
`app/models/team.rb:31-67`：`has_many :projects / protocols / repositories / reports / tags / assets / user_groups / forms / calendar_events / storage_locations / label_templates / repository_templates / team_shared_objects / shareable_links / activities`。`after_create` 钩子自动建模板项目、默认标签/库存模板。`storage_used`/`calculate_space_taken` 聚合统计资产字节数。成员经由 `team_assignments`/`user_assignments` 多对多接入。

### 2. User（用户）
`app/models/user.rb:60-334`：Devise 全家桶（invitable/confirmable/2fa/omniauth/lockable）+ API key（`regenerate_api_key!`）+ WOPI token。通过 `has_many :teams, through: :user_assignments` 加入团队；`has_many :user_my_modules` 分配到任务；拥有 `comments / results / steps / notifications / tokens / user_settings / favorites / view_states`。大量 `created_*/modified_*/archived_*` 关联仅作审计足迹（外键指 User）。

### 3. Project → Experiment → MyModule（项目/实验/任务）
- **Project** `project.rb:59-67`：`belongs_to :team`；`has_many :experiments`、`:reports`、`:project_comments`；含 `enum visibility: { hidden, visible }`；`ArchivableModel` 软归档。
- **Experiment** `experiment.rb:24-41`：`belongs_to :project`（`delegate :team`）；`has_many :my_modules`、`:my_module_groups`；`has_one_attached :workflowimg`。**画布式工作流**：任务带 `x/y` 坐标，`update_canvas`/`update_module_connections` 用 RGL 做拓扑排序并保证无环（`experiment.rb:436-486`）。
- **MyModule(task)** `my_module.rb:55-83`：核心任务实体。`belongs_to :experiment`；`has_many :results / taggings→tags / task_comments / protocols / steps(through protocols) / repository_snapshots / user_my_modules→designated_users`；`has_many :inputs/:outputs, class_name: 'Connection'` 表达任务间依赖；`belongs_to :my_module_status` 挂状态机。

### 4. Connection（任务依赖边）— 有向无环图
`connection.rb:4-5`：`belongs_to :to/:from, class_name: 'MyModule'`（即 `input_id→output_id`）。`ensure_non_cyclical` 校验无环，配合 Experiment 的拓扑序（`workflow_order`）确定执行顺序。

### 5. Protocol → Step（协议/步骤）
- **Protocol** `protocol.rb:85-145`：`belongs_to :my_module, :team`；**版本树**——`parent / previous_version / next_version / draft / published_versions / linked_children`；`has_many :steps`、`:protocol_keywords(through)`、`:repository_rows(through protocol_repository_rows)`。`protocol_type` 区分团队仓库协议与模块私有协议。
- **Step** `step.rb:39-56`：`belongs_to :protocol`；`has_many :step_texts / step_assets→assets / step_tables→tables / checklists / step_comments / form_responses / step_results→results`。步骤是实验操作的最小单元。

### 6. Result（结果）
`result.rb:10-13`：`belongs_to :my_module`；多态内容由 `ResultText / ResultAsset / ResultTable`（继承 `ResultBase`）承载；`has_many :result_comments / report_elements`。`ResultTemplate` 经 `belongs_to :protocol` 复用（`protocol.rb:141`）。`results_include_discarded` 暗示使用 `discard` 软删除。

## 三、关键子域（展开）

### A. 库存（Repository / EAV 模型）

实体与关联：

- **RepositoryBase**（抽象基类，`table_name='repositories'`，`repository_base.rb`）：`include Discard::Model`（软删除，`default_scope -> { kept }`）。`belongs_to :team / :created_by`；`has_many :repository_columns / :repository_rows / :repository_table_states / :report_elements`；`has_one :repository_stock_column`（`where(data_type: 'RepositoryStockValue')`）。特性开关（取自 `ApplicationSettings.instance.values`）：`stock_management_enabled?` / `repository_row_connections_enabled?` / `reminders_enabled?`。`has_stock_management?` = 开关开且列含 `stock_type`。`cell_preload_includes` 按列的 `EXTRA_PRELOAD_INCLUDE` 动态预加载。`destroy_discarded` 异步入队 `clear_discarded_repository`。
- **Repository**（继承 `RepositoryBase`）：团队库存库本体，`has_many :repository_snapshots`。
- **LinkedRepository**：`enum permission_level`（取自 `Extends::SHARED_OBJECTS_PERMISSION_LEVELS` 除 `shared_write`），表示跨团队共享库存的权限级别。
- **RepositoryColumn**（`repository_column.rb`）：`belongs_to :repository(RepositoryBase) / :repository_snapshot`；`has_many :repository_cells`、`:repository_rows(through cells)`、`:repository_list_items / :repository_status_items / :repository_checklist_items / :repository_stock_unit_items`（各可选项/单位）；`enum data_type: Extends::REPOSITORY_DATA_TYPES`（文本/数字/列表/资产/状态/清单/日期时间/时间/日期/各范围/库存/库存消耗）。**列名 i18n 本地化**：`name` 读时经 `RepositoryTemplate.localize_value` 还原（模板列名存 i18n key，非冻结于创建时）。`validates :data_type, uniqueness`（stock / stock_consumption 每库唯一）。`scope`：`list_type / asset_type / status_type / checkbox_type / stock_type / stock_consumption_type`。`deep_dup` 克隆各类型 items；`snapshot!` 列快照（额外生成库存消耗列）。
- **RepositoryCell**（`repository_cell.rb`）：`belongs_to :repository_row, :repository_column, :value(polymorphic)`。顶部哈希**动态生成 13 种 `<type>_value` belongs_to**（text/number/list/asset/status/checklist/date_time/time/date/date_time_range/time_range/date_range/stock/stock_consumption），值类与 `column.data_type` 严格对应（`repository_column_data_type` 校验 `value.class.name == data_type`）；`uniqueness(repository_row + repository_column)` 保证每行每列一个值。`scope with_active_stock_reminder` / `with_active_datetime_reminder` 实现低库存/临近到期提醒。`create_with_value!` 工厂按 `data_type.constantize.new_with_payload` 建值；`snapshot!` 行快照（含值快照）。
- **EAV 值类**（均 `has_one :repository_cell, as: :value`）：`RepositoryTextValue / RepositoryNumberValue / RepositoryListValue / RepositoryAssetValue / RepositoryChecklistValue / RepositoryDateTimeValueBase`（及 Time/Date/Range 子类）/ `RepositoryStatusValue`（`belongs_to :repository_status_item`）/ `RepositoryStockValue` / `RepositoryStockConsumptionValue`。
  - **RepositoryStockValue**（`repository_stock_value.rb`）：`belongs_to :repository_stock_unit_item`（计量单位）；`has_many :repository_ledger_records`。`status`（`:empty/:low/:normal`，依 `amount` 与 `low_stock_threshold`）。`after_create` 写首条 `repository_ledger_records`（余额=amount）；`after_save` 低库存时 `LowStockNotification.send_notifications`。`update_data!` 计算 delta 并写流水账（`balance=new_amount`）。`formatted` = 数量+单位（精度取 `column.metadata['decimals']`）。`import_from_text("12 mg")` 解析数字与单位并自动建 `repository_stock_unit_item`。
  - **RepositoryStockConsumptionValue**：消耗追踪，步骤消耗库存时记录。
- **RepositorySnapshot**（继承 `RepositoryBase`，`repository_snapshot.rb`）：`enum status: { provisioning, ready, failed }`；`belongs_to :original_repository(Repository) / :my_module`；`has_one :repository_stock_consumption_column`；`validates :selected, uniqueness`（每 `my_module` 仅一个 selected）。`create_preliminary!` 建预快照；`after_save refresh_report_references` 切换报告引用。由状态机 `MyModuleStatusConsequences::RepositorySnapshot` 在进入终态时创建（见子域 B）。
- **RepositoryLedgerRecord**（`repository_ledger_record.rb`）：库存流水账。`belongs_to :repository_stock_value, :reference(polymorphic: RepositoryBase 或 MyModuleRepositoryRow), :user`；记录 `amount / balance`；当 `reference=MyModuleRepositoryRow` 时校验 `my_module_references`（team/experiment/project/my_module id 齐备）。
- **StorageLocation**（`storage_location.rb`）：`belongs_to :team, :parent`（层级）；`has_one_attached :image`；`has_many :repository_rows(through :storage_location_repository_rows)`——库存物理位置。
- **RepositoryTableState / RepositoryTableFilter / RepositoryTableFilterElement**：UI 表格视图状态与过滤条件（`belongs_to :repository`）。
- **RepositoryTemplate**（`repository_template.rb`）：`belongs_to :team`，`has_many :repositories`。预定义模板（default / cell_lines / equipment / chemicals_and_reagents，见 `team.rb` 的 `create_default_repository_templates`）；`localize_value` 本地化列名 i18n key。
- 选项/单位实体：`RepositoryStatusItem / RepositoryChecklistItem / RepositoryListItem / RepositoryStockUnitItem`（均 `belongs_to :repository_column`，供对应列类型选择）。

### B. 任务状态机（MyModuleStatusFlow）

结构：`MyModuleStatusFlow`（流程）→ `has_many MyModuleStatus`（状态，链表）→ 每状态 `has_many conditions / consequences / implications`。

- **MyModuleStatusFlow**（`my_module_status_flow.rb`）：`enum visibility: { global, in_team }`；`belongs_to :team(optional)`。`initial_status` = `previous_status` 为 nil 者；`final_status` = `next_status` 为 nil 者。`ensure_default` 从 `Extends::DEFAULT_FLOW_STATUSES` 构建默认全局流程（每个状态带 `conditions/implications/consequences` 类名列表）。
- **MyModuleStatus**（`my_module_status.rb`）：**链表** `belongs_to :previous_status` / `has_one :next_status`（同 flow 校验 `next_in_same_flow` / `previous_in_same_flow`）。`initial_status?` / `final_status?`；`sort_by_position` 拓扑排序；`conditions_errors(my_module)` 克隆 my_module 运行各 `condition.call` 做进入前置校验；`MyModuleStatusTransitionError`。
- **状态流转守卫**（`my_module.rb`）：`check_status`（`:574`）仅允许转到相邻 `next_status` / `previous_status`，否则报错。
- **后果执行**（`my_module.rb:584` `exec_status_consequences`）：依据 `my_module_status.previous_status_id == my_module_status_id_was` 判定 `:forward` / `:backward` 方向；forward 时先调各 consequence 的 `before_forward_call(self, status_changed_by)`；再按 `runs_in_background?` 用 `MyModuleStatusConsequencesJob` 异步（`.perform_later`）或同步（`.perform_now`）执行 `forward` / `backward`。
- **MyModuleStatusCondition**（基类 `belongs_to :my_module_status`；`call(my_module)` 向 `errors` 加信息）→ 子类 `Active`（`my_module_status_conditions/active.rb`：要求 `my_module.active?`）。
- **MyModuleStatusConsequence**（基类 `forward/backward/before_forward_call/runs_in_background?`）→ 子类：
  - `Completion`（`forward`：置 `state='completed'`、`completed_on=now`）——与 `MyModule#completed?` 谓词一致（`Extends::TASKS_STATES` enum）。
  - `Uncompletion`（`backward`：仅在 `state=='completed'` 时置回 `uncompleted`，清 `completed_on`）。
  - `RepositorySnapshot`（`runs_in_background?=true`；`before_forward_call` 遍历 `my_module.assigned_repositories` 建 `::RepositorySnapshot.create_preliminary!` 并记 activity；`forward` 经 `Repositories::SnapshotProvisioningService` 实际快照，首个快照自动 `selected=true`）。
  - `ChangeActivity`（示例实现，`call` 仅 `puts` 日志——注释标明待替换）。
- **MyModuleStatusImplication**（基类 `description`）→ 子类 `ReadOnly`（`my_module_status_implications/read_only.rb`：`call` 加错误，标记进入该状态后任务只读）。
- **与 MyModule 关联**：`my_module.rb:60` `belongs_to :my_module_status`、`belongs_to :changing_from_my_module_status`。
- **纠正**：`ReadOnly` 是 *Implication*（进入约束）而非 *Consequence*；之前文档误将其列在 consequence 中，此处订正。

### C. 权限模型

赋权三表（均 `belongs_to :assignable, polymorphic: true`，可挂在 Team/Project/Experiment/MyModule/Repository 等）：

- **UserAssignment**（`user_assignment.rb`）：`belongs_to :user_role / :user / :team / :assigned_by`；`enum assigned: { automatically, manually }`；`scope with_permission` 用 `? = ANY(user_roles.permissions)`（PostgreSQL 数组包含）；`last_assignable_owner?`。Team 赋权触发级联：`assign_team_child_objects`（经 `UserAssignments::CreateTeamUserAssignmentsService`）、`update_team_children_assignments`、`unassign_team_child_objects`，并级联删 `user_group_memberships`。
- **UserGroupAssignment**（`user_group_assignment.rb`）：同结构，`belongs_to :user_group`（以用户组为单位赋权，参与权限 UNION）。
- **TeamAssignment**（`team_assignment.rb`）：`belongs_to :team`（团队级赋权，作用于该团队内所有对象）；`delegate :users, to: :team`。
- **UserRole**（`user_role.rb`）：`permissions` 为 PostgreSQL `varchar[]`；4 个预定义角色 `owner / normal_user / technician / viewer`（权限集取自 `PredefinedRoles::*_PERMISSIONS`，`predefined` 角色禁止更新）；`has_permission?(p) = permissions.include?(p)`；`owner?` / `viewer?`。
- **PermissionCheckableModel** concern（核心判定，`concerns/permission_checkable_model.rb`）：
  - `permission_granted?(user, permission, permission_team = user.permission_team)`：先查 `user_assignments`（直接）；否则 `UNION` 查 `team_assignments` + `user_group_assignments`，均用 `user_roles.permissions @> ARRAY[?]::varchar[]` 包含运算。
  - `with_granted_permissions` scope：合并 用户 / 组 / 团队 三种来源（`UNION`，直接赋权优先）。
  - `readable_by_user` / `managable_by_user`：取 `::<Model>Permissions::READ` / `::MANAGE`（按类名推导权限常量模块）。
- **Assignable** concern（`concerns/assignable.rb`）：注入 `user_assignments / user_group_assignments / team_assignments` 多态关联与自动赋权钩子；`users` 聚合三来源；`create_user_assignments!` 继承 `permission_parent` 的赋权（顶层对象 owner 给创建者，其余从父级 user/group/team 赋权继承），后台 `UserAssignments::InheritUserAssignmentsJob` 批量继承；`reset_all_users_assignments!` 重建。
- **权限常量（Canaid gem）**（`app/permissions/*.rb`）：`Canaid::Permissions.register_for(Model)` + `can :permission do |user, obj| ... obj.permission_granted?(user, XPermissions::READ) end`。例 `project.rb`：`ProjectPermissions::READ / MANAGE / EXPERIMENTS_CREATE / COMMENTS_READ / COMMENTS_MANAGE / COMMENTS_MANAGE_OWN / USERS_READ / ACTIVITIES_READ` 等；部分权限附加前置条件（如 `project.active?`、或 team `MANAGE` 提升）。

### D. 协作与日志（多态关联）

- **评论**：`Comment` 基类（`comment.rb`：`belongs_to :user, :last_modified_by`；`unseen_by` PostgreSQL 数组；`mark_as_seen_by` 用 `array_remove`）。四个子类统一用 `associated_id` 外键多态挂接：`ProjectComment`（`project`，`project.rb` 的 `project_comments`）、`TaskComment`（`my_module`）、`ResultComment`（`result`）、`StepComment`（`step`），均 `foreign_key: :associated_id, touch: true`。
- **标签**：`Tag`（`tag.rb`：`belongs_to :team, :created_by, :last_modified_by`；`has_many :taggings`）+ `Tagging`（`tagging.rb`：`belongs_to :tag, :taggable(polymorphic)`；`uniqueness(tag_id + taggable)`）。MyModule 经 `taggings` 关联 `tags`。
- **通知**：`Notification`（`notification.rb`：`include Noticed::Model`；`belongs_to :recipient, polymorphic`；`scope :in_app` 依 `params['hide_in_app']`；`after_create` 经 `UserNotificationsChannel.broadcast_to` 推未读计数）。设置存 `UserSetting(key: 'notifications_settings')`。
- **活动日志**：`Activity`（`activity.rb`：`enum type_of: Extends::ACTIVITY_TYPES`；`belongs_to :owner(User), :subject(polymorphic, optional), :project / :team / :experiment / :my_module`；`store_accessor :values, :message_items, :breadcrumbs`；`include GenerateNotificationModel`；`after_create → Activities::DispatchWebhooksJob` 派发 webhook）。`generate_breadcrumbs` 递归父链（Protocol→Team / MyModule→Experiment→Project→Team / Result→MyModule 等），`ACTIVITY_SUBJECT_PARENTS` 由 `Extends::ACTIVITY_SUBJECT_CHILDREN` 反转得到。写入统一经 `Activities::CreateActivityService.call`。
- **报告**：`Report`（`report.rb`：`belongs_to :project / :user / :team`；`has_many :report_elements`；`has_one_attached :pdf_file / :docx_file / :docx_preview_file`；`enum pdf_file_status / docx_file_status`；`DEFAULT_SETTINGS` 含丰富导出项；`generate_whole_project_report` 整项目导出）。`ReportElement`（`report_element.rb`：`enum type_of: Extends::REPORT_ELEMENT_TYPES`；层级 `parent / children`；`belongs_to` 引用 `project / experiment / my_module / step / result / checklist / asset / table / repository(RepositoryBase)`）。

### E. 其它重要实体

- **用户组**：`UserGroup`（`user_group.rb`：`belongs_to :team`；`has_many :user_group_memberships→users, :user_group_assignments`；`enabled?` 取自 `ApplicationSettings.values['user_groups_enabled']`）；`UserGroupMembership`（`belongs_to :user_group, :user`）；`UserGroupAssignment`（组级赋权，见子域 C）。

- **资产**：`Asset`（`asset.rb`：ActiveStorage `has_one_versioned_attached :file / :preview_image` + `:file_pdf_preview`；`include VersionedAttachments / ArchivableModel / ObservableModel`；`WOPI_LOCK_DURATION=30min`）。`belongs_to :team, :created_by`；`has_one :step_asset→step, :result_asset→result(Base), :repository_asset_value→repository_cell`；`has_many :report_elements, :asset_sync_tokens`。校验 step/result/repository 三者互斥。写文件时 `update_estimated_size` 并累加 `team.space_taken`。WOPI 集成（`can_perform_action` / `get_action_url` / `wopi_lock_*`）支撑 Office Online 协同编辑；`AssetTextDatum` 存文本向量供搜索。

- **设置**：`Settings`（基类，`settings.rb`：单例 `instance`；`values` 合并 `load_values_from_env`）；`ApplicationSettings`（继承 `Settings`，`load_values_from_env` 读 `APP_STTG_*` 环境变量）；`UserSetting`（`belongs_to :user`，`key/value` 键值对，如 `notifications_settings`）；`User#variables`（`export_vars` 导出限额计数）。

## 四、横切关注点
- **软删除/归档**：`ArchivableModel`（`archived` 标志，Project/Experiment/MyModule 等）+ 部分 `discard`（Result / RepositoryBase / FormResponse）。
- **审计足迹**：几乎每个实体都 `belongs_to :created_by/:last_modified_by/:archived_by/:restored_by`（User），`TimeTrackable` 注入时间戳。
- **可搜索**：`SearchableModel`/`SearchableByNameModel` 提供 `self.search(user, ...)` + `readable_by_user` 链式作用域（团队/项目/实验/任务均实现）。
- **前缀 ID**：`PrefixedIdModel` 给 Project(`PR`)/Experiment(`EX`)/Report(`RP`)/Form(`FR`) 等业务主键加可读前缀。

# 06 — 文档与图谱解析（AI-101~103）

**What to build:** 附件解析能力：AI-101 PDF 解析（DSC/TGA/论文，提取文本/表格，可导入笔记，支持多页）、AI-102 图片 OCR+实验草稿解析（手写照片/图谱截图，OCR 区分样品编号/配方配比/测试数据/现象备注，双轨后端本地/公有，结果预览用户确认后填入）、AI-103 仪器 CSV 解析（关键指标预览表，确认后复制）。>10MB 文件走 Delayed Job 异步。

**Blocked by:** 04 — AI 侧边抽屉 UI 与权限条件渲染

**Status:** ready-for-agent

- [ ] AI-101 PDF 解析：多页文本/表格提取，可导入笔记
- [ ] AI-102 OCR：双轨后端（按 `ocr_backend` 开关），解析结果分类+预览+用户确认
- [ ] AI-103 CSV 解析：关键指标预览表，确认后复制
- [ ] 大文件（>10MB）经 Delayed Job 异步，避免页面超时
- [ ] 解析结果禁止自动写入原始记录，仅预览+用户确认
- [ ] 符合 ADR-0004（异步管道）、OCR 双轨（规格 V1.1 §2.2）

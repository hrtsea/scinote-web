# 05 — 实验记录 AI 辅助（AI-001~004）

**What to build:** 实验页面的 AI 辅助能力：AI-001 实验方案生成（目标/物料/约束→步骤/现象/风险，存附件）、AI-002 文本规范化润色（选中 StepText/ResultText，润色版存附件，原文不变）、AI-003 实验自动小结（基于实验全部字段+附件）、AI-004 失败现象根因分析（检索本项目历史，给参考清单）。全部输出预览、人工确认，绝不自动写入原始记录。

**Blocked by:** 04 — AI 侧边抽屉 UI 与权限条件渲染

**Status:** ready-for-agent

- [ ] AI-001 方案生成：输入→AI→结果存附件，用户手动复制
- [ ] AI-002 润色：选中笔记文本→润色版作为附件，原始 StepText/ResultText 不变
- [ ] AI-003 小结：基于当前实验字段+附件生成周报草稿
- [ ] AI-004 根因分析：失败现象→检索本项目历史→潜在根因清单（仅参考）
- [ ] 全部结果标记"AI 辅助生成，需人工审核"
- [ ] 符合 ADR-0001（关联 StepText/ResultText）、ADR-0003 不涉及、ADR-0004（管道）

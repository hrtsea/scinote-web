# 16 — `#<实验ID>` 只是一次性定向，不得切换「当前草稿」

**What to build:** 让 `#<实验ID> 文本` 只决定**这一条消息**的落点，**不再**改写本地草稿索引。

**Why:** 现状 `#<ID>` 内部调用的就是切换草稿那条路径，于是产生了一个隐蔽的行为：**一条「挂到 #12」会静默改变之后所有消息的落点**，直到用户察觉以前，后续录入全走错了地方。用户的心智里「#」是一次性定向（「这条发到那儿」），而不是模式切换。这个落差会造成真实的数据错配。

**ADR:** 0025（把「消息级指定」与「会话定向」确立为两个术语）｜**术语表:** 「消息级指定 vs 会话定向」

**Blocked by:** 12（同改 `#` 的落点逻辑，顺序推进避免互相覆盖）

**Status:** ready-for-agent

- [ ] `#<实验ID> 文本`：校验可见 → 追加正文到该实验 → **不动本地草稿索引**
- [ ] `#<实验ID>` 后无正文时不产生「已切换到」的措辞，改为「本条已挂到 #N」的说明式文案
- [ ] `/setexp <实验ID>` 保持「切换」语义不变——它才是会话定向
- [ ] `/help` 里把两者写成两行，各自一句话说清差别
- [ ] 更新 `docs/指令参考.md`：「消息级指定 ≠ 会话定向」

**验收：** 先 `/setexp 1`，再 `#2 测试`，再发一条普通文本 —— 最后一条应落到 `#1`，且全程草稿索引未被 `#2` 改动。

# 20 — `/newtask` 目标解析与两级引导（含行内 ID 的破坏性删除）

**What to build:** `/newtask` 不再接受行内实验 ID，语法收敛为 `/newtask [任务名] [~截止]`；目标实验由统一解析顺序决定（ADR 0028 §1）：**当前实验 → 默认实验 → 默认项目下的实验候选 →（无项目）先选项目再选实验**。

**Why:** 现状三宗罪：
1. **缺容器时只回用法错误** —— 用户得先 `/listexp` 抄一个 ID 再回来，凭空多两次往返；
2. **目标裸取** —— `Experiment.find(id)` 无可见性校验，违反 ADR 0025（ticket 11/13 待做）；
3. **行内首位数字的猜测语义** 与待选态「纯数字 = 选编号」直接撞车——同一条消息两种解释，而猜错的代价是把任务建到一个陌生实验里。

**ADR:** 0028 §1 / §3 / §4 / §7 ｜ **术语表:** `addons/wechat_gateway/CONTEXT.md` §5 L2、§6「默认实验 / 可建」

**Blocked by:** 11（候选可见性基座）、13（`can_create_experiment_tasks?` 写权限矩阵）、19（pending 泛化）、21（默认实验与统一解析入口）

**Status:** blocked（先过闸，再开门 —— 见评论）

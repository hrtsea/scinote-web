# 22 — 空候选与失效目标必须有明确提示（禁止自动代建）

**What to build:** 引导链条上所有「没有候选 / 目标失效」的分支都要有明确回复：说清**为什么没有**，并给**至少一条可执行下一步**。覆盖五类：无任何可建项目、无任何可建任务的实验、项目下还没有实验、目标实验已归档、目标已无写权限。

**Why:** 盘问 Q7 明确否决了「自动帮他建一个实验再把任务挂进去」——在用户不知情处创建名为 `微信记录-<uid>` 的实验，会让他到 Web 端看到一个自己完全不认识的容器，而网关按 ADR 0027 还不提供删除。既然不代建，就必须把死胡同说清楚；否则用户的唯一反馈是反复发同一个指令。
